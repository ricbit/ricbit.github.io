msxzin is a full-featured MSX1 emulator in just 4 KB. It runs under DOS on any 8086-compatible CPU.

Features

Z80 CPU

  • Verified by ZEXDOC
  • IM 0, IM 1 and IM 2
  • Undocumented opcodes

VDP emulation

  • SCREEN 0, 1, 2 and 3
  • 8×8 and 16×16 sprites
  • Magnified sprites
  • 5th sprite occlusion
  • Sprite collision
  • VDP prefetch
  • Mirrored color/pattern tables

Sound

  • Wave-based PSG and SCC emulation
  • PSG logarithmic volume scale
  • PSG envelopes

ROM cartridges

  • Any ROM size, including MegaROM
  • Automatic MegaROM mapper detection
  • MegaROM mappers
    • Konami
    • Konami with SCC
    • ASCII 8 KB
    • ASCII 16 KB
    • R-Type

Disk images

  • DSK files
  • 180 KB, 360 KB and 720 KB
  • Read and write support

Cassette images

  • CAS file support

Requirements

Runs in DOS on any 8086-compatible CPU. EMS memory is required for cartridges. bios.rom and disk.rom must be present in the emulator directory.

Bundled with Gradiente Expert 1.1 BIOS and CDX-2 disk interface ROMs. C-BIOS is supported as well.

Sound requires a Sound Blaster 16 at 220h, IRQ 5, with DMA. On modern machines, use DOSBox.

On errors such as insufficient memory or missing BIOS files, msxzin returns to the DOS prompt.

Usage

Run the emulator without parameters to enter MSX BASIC. To load a ROM, CAS or DSK image, pass the file as the first parameter.

msxzin is a DOS binary, so filenames must follow the DOS 8.3 format. 

msxzin
msxzin salame.rom
msxzin deathw3.cas
msxzin elite.dsk
